# 코드리뷰 후속 기능

버전은 사용자 요청 전까지 0.3.2를 유지합니다. 아래 목록은 코드리뷰의 기능 제안을 추적하는 것이며, 모두 구현되었다는 뜻이 아닙니다.

## 이번 우선 적용 범위

- 백업 공유·내보내기: Android 파일 선택으로 읽기 권한을 받고 공유하거나, 비어 있음이 확인된 대상에 스트리밍 복사합니다. 원본 삭제·재압축·자동 업로드는 하지 않습니다. 선택한 문서는 런처 소유가 아니므로 실패·취소 시에도 삭제하지 않습니다. 쓰기가 시작된 뒤 중단됐다면 대상에 미완성 파일이 남을 수 있습니다.
- 마지막 백업 알림: 사용자 데이터·전체 백업의 확인된 생성 기록을 사용합니다. 설정한 주기(1일·7일·30일)에 따라 백업 탭의 점과 홈의 ‘마지막 백업’ 강조로 알려줍니다. 파일이 지금도 존재한다는 뜻은 아니며, 백그라운드 조회·예약 백업·시스템 알림은 없습니다.
- 업데이트 변경 내역 미리보기: 기존 안전 검사에서 가져온 커밋 범위의 제목을 최대 20개 표시합니다. 추가 fetch는 하지 않고, 미리보기 실패가 안전 검사 성공으로 오인되지 않도록 결과를 구분합니다.

## 7단계 후속 구현 범위

- 내부 안전 사본 목록·용량·내보내기·선택 삭제
- 초기화 전 백업 유도, 복원 미리보기 강화(항목 수·버전 호환 경고)
- 위험 작업 UI 정리, 태블릿·큰 글꼴 레이아웃, 문자열 리소스 분리
- 서버 종료→작업→재시작 연결, 시작 후 브라우저 자동 열기 옵션
- 로그 검색·강조·공유, 오류별 해결 동작 연결
- 런처 자체 업데이트 확인, Node 패키지 업데이트 정보
- 확장 프로그램 관리, 파일 다중 선택·검색·미리보기
- 외부 접속 개선, 백업 보존 정책·암호화, 저장 공간 대시보드
- 이전 버전으로 되돌리기, 바로가기·타일·위젯, 캐릭터·채팅 단위 부분 복원

위 항목을 7단계로 나누어 구현했으며, 단계별 검증 결과와 남은 기기 검사는 [실행 기록](IMPLEMENTATION-STAGES.md)에 기록합니다. 안전 사본의 자동 삭제나 외부 접속 확대는 기본 동작으로 추가하지 않습니다. CI 통과와 실제 Android·Termux 기기 동작 검증을 구분합니다.

## 전체 리뷰 00d9ef6 후속 (검증 브랜치)

- **PC ZIP:** 동명 카드·카드 없이 남은 대화·그룹의 비활성 멤버까지 확인해 잘못 연결될 자료만 건너뜁니다. 페르소나는 그림만 더하며 이름·설명·캐릭터 태그는 합치지 않습니다. 미리보기에 제외 종류 및 연결 때문에 건너뛴 수를 표시합니다. 교체 전에는 휴대폰에만 있는 카드·대화·사용자 수를 요청해서 확인할 수 있습니다. 정확히 셀 수 없으면 0이 아닌 ‘확인할 수 없음’입니다.
- **작업 경계:** 서버 종료·사전 백업이 실패해도 현재 화면에 아직 넘기지 않은 ZIP을 유지합니다. 실제 반영을 요청한 뒤 결과가 불명확하면 자동으로 재시도하지 않습니다. 반영 영수증이 검증됐고 정리만 남았다면 성공으로 표시하되 안전하지 않은 다음 변경은 계속 막습니다.
- **카드·휴지통:** 채팅 폴더까지 이름을 바꾸거나 옮긴 뒤에는 기존 브라우저 탭에서 새로고침해야 한다는 안내를 확인할 때까지 남깁니다. 카드만 옮기면 남는 대화 수도 알립니다. 읽을 수 없는 카드와 그룹 연결 등을 구분합니다. 브라우저를 강제로 새로고침하거나 예전 이름의 대화를 자동으로 합치지는 않습니다.
- **추가 점검:** 업데이트에서 Git이 수정 파일을 확인할 수 없으면 진행하지 않습니다. 업데이트 완료와 서버 재시작 결과, 확장 일괄 처리의 부분 성공과 실제 오류 코드, 외부 접속 설정 저장과 디스크 기록 경고를 구분합니다. 백업 내보내기에서 파일 선택기의 문서를 런처 소유라고 추정하지 않습니다.
- **성능·한계:** 검증 워크플로는 임시 Linux 설치에서 256 MiB 상당 ZIP의 미리보기·서버가 꺼진 동안의 합치기와 카드 2,048장 목록의 첫 페이지·전체 페이지를 측정합니다. 실제 휴대폰 Termux, 기기별 저장장치·파일 제공자, 브라우저 탭은 별도 검사 대상입니다. 60초 이내 런처 복귀의 가벼운 응답 확인, 불확실한 카드 연결의 복사 우선, 기존 백업 기본 범위는 변경하지 않았습니다.

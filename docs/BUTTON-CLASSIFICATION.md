## 단독 닫기 8곳

| 대상 | 결과 |

| 열 앱 선택 | 버튼 3개 대신 앱 목록과 ‘항상 이 앱으로 열기’ 스위치. 단순히 시트를 열거나 스위치를 켜는 것으로 앱을 실행하지 않음. |
| 안전 사본 확인 | 진행할 수 없을 때 ‘확인’ Primary. 삭제·복원이 가능한 경우의 확인 절차는 유지. |

| 바로가기 요청 | 실행할 수 없으면 ‘확인’만 제공. 실행 요청을 보내지 않음. |
| 공간 정리 미리보기 | 별도 화면과 뒤로 가기. 아무것도 선택하지 않은 상태에는 삭제 버튼 없음. |

| 이전 버전 | 준비되지 않은 상태는 ‘확인’ Primary. 확인 단계의 ‘이전’은 Quiet. |
| 오픈소스 라이선스 | 상세 → 라이선스 목록 → 앱 정보. 상단·시스템 뒤로, 별도 닫기 버튼 없음. |

## 공통 기준

- 표에서 유지한 Outline은 #16·19·22·29·35·37·38·40·41·44. 보조는 44dp, 고정 하단은 52dp 기준이며 큰 글씨에서는 늘어날 수 있습니다. 링크·상단 동작에 밑줄은 없습니다.
- 연속된 이동 행은 한 목록으로 묶습니다. 아이콘을 글자로 일괄 교체하지 않습니다. 작업 로그 복사는 접근성 이름이 있는 아이콘이며 스낵바의 ‘닫기’에 테두리는 없습니다.
- `python scripts/check_action_affordances.py`: 허용되지 않은 직접 TextButton 사용을 검사합니다. 폰·태블릿 계측 테스트는 파일·확장·백업·온보딩 등 실제 화면의 탐색과 콜백을 검사합니다.

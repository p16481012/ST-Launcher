기준 커밋: `1346155`. 앱 버전 `0.3.2`, 코드 `5` 유지. PR 없이 단계별 커밋·자동 검증을 사용하며 공개 릴리스는 별도 요청 전 변경하지 않습니다.

각 단계에서 독립 코드 검토, 관련 단위·격리 시뮬레이션, 전체 회귀 검사·빌드, 서명 APK 검증을 수행합니다. 실제 Android 파일 제공자·OS 프로세스 정책 검증은 자동 검사와 구분합니다. 검증하지 않은 결과를 통과로 기록하지 않습니다.

## 안전 경계

- 원본 삭제, 백업 정리, 외부 접속, 확장 변경은 사용자의 앱 내 확인을 거칩니다.
- 진행 중 작업이나 미완료 복구에 필요한 자료는 일반 정리 대상에서 제외합니다.
- 버전 다운그레이드나 데이터 롤백은 백업 없이 자동 적용하지 않습니다.
- 백업 암호는 로그·설정 파일·작업 결과에 저장하지 않습니다. 외부 접속용 기본 인증은 SillyTavern의 config.yaml에 필요하지만 런처 설정·로그에는 보관하지 않습니다.
- 파일 제공자가 응답하지 않거나 안전성을 확인할 수 없는 경우 원본을 유지하고 명확한 안내로 중단합니다.

## 검증 기록

### 1단계

- 구현: 공유 파일 nonce 읽기 검사(가져오기 전·명시적 진단만), Android가 보고한 프로필별 공유 경로, Termux 설치 출처/복사용 서명 정보, 접힌 강제 종료 도움말, 설정 파일 포트 표시.
- 회귀 방어: 읽기 검사 실패가 기존 백업 목록을 숨기지 않음. Android 8/9에서는 기존 백업 사용을 유지하며 실제 공유 파일 검사의 한계를 안내.
- 로컬 격리 검사: `test-manager-storage.sh` 통과(정상 읽기, 내용 불일치, 읽기 거부, 경로, config.yaml 읽기 전용 검사). Windows에서는 실제 심볼릭 링크 검사를 건너뛰므로 Linux CI로 보완.
- 독립 정적 검토: 저장소·환경 구성 상호 검토 완료. Android 컴파일/단위 검사·전체 Linux 회귀는 CI 확인 전이며, 실제 기기의 MediaStore 제공자 검증은 별도.
- 최초 CI `45198140804`에서 API 29 분기를 Lint가 인식하지 못해 실패. 명시적인 SDK 분기로 고친 커밋 `1353d2f`, CI `45200604935`에서 Linux 안전 검사·반복 시뮬레이션, Android 테스트·Lint·debug/release 빌드 모두 통과.

### 2단계

- 내부 안전 사본·설정 사본·다중 휴지통 목록, 날짜/용량/완료 기록 구분, 명시적 내보내기·영구 삭제·원위치 복원. 미완료 복구/알 수 없는 작업 자료는 변경 차단.
- 내보내기는 전용 새 폴더에 한 번만 복사. 다른 프로세스의 `/proc/<pid>/fd` 접근·하드링크·2차 전체 복사를 사용하지 않음. 일반 취소 시 자신이 만든 파일만 정리하며 강제 종료 시 `INCOMPLETE.txt` 유지.
- 초기화 전 전체 ZIP 백업 기본 선택 및 최근 생성 기록 안내. 백업 실패/취소 시 초기화하지 않으며 프로세스 재시작 뒤 자동 초기화하지 않음.
- 백업 생성의 기존 ZIP 목록 순회를 재사용해 캐릭터 PNG·채팅 JSONL 파일 수 저장. 이전 백업은 미확인으로 표시. 복원 시 버전 차이·오래된/알 수 없는 날짜 경고. 롤백 결과에서 ZIP 백업 화면 연결.
- 로컬: 메타데이터/관리 작업 연결 검사 통과, 안전 목록 19개 회귀 그룹 및 완료 마커 7개 오류 주입 그룹 통과. 심볼릭 링크 검사는 샌드박스 EPERM 이후 동일한 격리 테스트를 권한 확보하여 재실행·통과.
- 독립 검토에서 완료 후 목록 갱신 취소가 작업 실패로 기록될 가능성을 수정. 최종 정적 검토 통과. 최초 CI에서 기존 임시파일 검사가 새 완료 마커를 오인하던 문제를 수정. `1353d2f`의 CI `45200604935` 전체 통과.

### 3단계

- 타입·인자 검증을 갖춘 저장 가능한 확인창, 선택 브랜치·백업 선택 복원. 재시작 후 확인창만 복원하며 작업을 자동 실행하지 않음. 문서 읽기 권한을 다시 확인.
- 위험 작업 접기, 브랜치 변경/다운그레이드 경고, 종료 상태 재시작 버튼 숨김. 600dp 이상 탐색 레일, 긴 정보·큰 글꼴 줄바꿈, 탭, 시스템 테마 동적 색상, 상태 색상 대비.
- 모달 작업창의 바깥 터치 차단. 접힌 패널에 단계·전체 경과 시간·실측 처리량만 표시. 두 개의 16ms 수동 회전 루프 제거.
- XML·diff 정적 검사 통과, 독립 코드 검토 완료. 새 JUnit 13개는 CI 실행 전. 실제 200% 글꼴·TalkBack·회전·테마 조합 절차는 `ADAPTIVE-UI-COMPONENTS.md` 참고.

### 4단계

- 로그 리터럴 검색·강조(최대 500개), 수동 따라가기, 마스킹 후 공유. 정규식 실행·무제한 검색 없음.
- 현재 폴더의 검색·정렬·다중 휴지통 이동(최대 200개), 파일 revision 재검사와 부분 완료 수 기록. 텍스트 앞부분 24KiB 읽기 전용, 작은 PNG(24KiB/512px) 이미지, 큰 카드의 제한된 이름·설명 미리보기. 전체 대용량 이미지는 외부 열기 사용.
- 백업·서버 연결 설정은 명시적 확인 뒤 중지→작업→원래 실행 중일 때만 재시작. 취소 뒤 자동 재시작 금지. 성공 작업 뒤 재시작 실패는 원래 작업 성공과 분리.
- 시작 후 브라우저 자동 열기 기본 꺼짐. 직접 시작·화면 표시·정상 응답일 때만 동작. 수동 런처 릴리스 조회와 캐시 기준 Node 패키지 정보, 자동 다운로드/설치 없음.
- 로컬 파일 미리보기/경로/오래된 revision 거부, Node 캐시 정보, 기존 파일 관리 회귀 통과. 독립 백엔드·서버 연계 정적 검토 완료. 신규 Kotlin·Android 전체 검증은 CI 대기.

### 5단계

- 저장 공간 수동 검사: 최대 15초/250,000항목, 중복 inode 한 번 집계, 링크를 따라가지 않음. 누락·제한 도달 시 일부 미확인으로 표시. 앱 시작에 자동 실행하지 않음.
- 백업 고정·메모(앱 내부), 보관 개수/기간으로 정리 후보 미리보기. 기본 선택/예약 자동 삭제 없음. 고정·알 수 없는 날짜 보호, 실행 직전 목록·고정·파일 식별 재검사.
- 선택 삭제는 최대 200개. 독립 검토에서 복구 중 검사/삭제의 자동 복구 부작용과 삭제 격리 폴더 링크 경계를 보완. 실패 시 미완료 격리 사본과 복구 안내를 남기며, 원래 이름을 무조건 덮어쓰지 않음.
- 저장 공간 8그룹, 백업 삭제 5그룹 로컬 통과. Linux에서 격리 폴더 교체 공격 추가 검사 예정.
- Windows/Git tar 기준 실측: 작은 파일 4,000개(2,048,000B) 공간 검사 195ms·압축 25,081ms·관측 추가 공간 2,257,581B; 64MiB+16파일 검사 93ms·압축 2,434ms·관측 추가 공간 67,139,125B. 50ms 표본이며 정확한 최대 점유량/Android 속도 보장이 아님. 임시 벤치마크 데이터 정리 완료.
- 복원 중복 복사와 300초 시작 제한은 저널/실기기 근거 없이 바꾸지 않음. 복원 저널과 연계한 안전한 이동 최적화 검토를 7단계에서 이어감.

### 3~5단계 통합 검증

- CI `45203216775`, `45203911389`에서 Compose 내부의 `Context.getString` 사용 8건이 Lint 오류로 검출됨. `LocalResources`로 수정했으며 검사 억제는 추가하지 않음.
- 커밋 `e8b2e4a`, CI `45205614998`에서 Linux 회귀·2회 반복 시뮬레이션, Android/JVM 테스트·Lint·debug/release APK 빌드·기존 버전/패키지 식별 검사 전체 통과.
- Linux 전용 백업 삭제 격리 폴더 교체 공격 검사도 통과. 이 결과는 실제 기기의 파일 제공자·TalkBack·배터리 제한 동작을 대신하지 않음.

### 6단계

- 확장: 지원하는 클라이언트 확장만 목록·사용/중지·휴지통 이동·업데이트. HTTPS GitHub 원본 및 깨끗한 독립 Git 구조만 갱신하며 사용자 수정·특수 Git 설정·링크는 자동 변경하지 않음.
- 준비 복사부터 durable receipt를 기록하고 원본/임시/대상 inode를 확인. 중간 강제 종료는 확장 관리의 복구로 처리하며 미확인 경로는 보존. 로컬 21개 회귀 그룹(준비·원격 확인·정리·교체 경계 SIGKILL 포함) 통과, Linux 전용 분기 CI 대기.
- LAN 주소·QR은 수동 조회. 외부 접속/허용 사설 IP·CIDR/기본 인증은 위험 안내와 명시적 확인 후 설정. 암호는 Intent/명령행/표준입력 로그에 싣지 않고 만료되는 일회성 루프백 전달을 사용. SillyTavern config.yaml에는 기능상 인증값이 저장됨.
- LAN YAML 실검사 14그룹 2회 통과. 401 인증 응답도 서버 응답으로 인식함. 바로가기·빠른 설정 타일·위젯은 전경 확인 화면으로만 연결하며 직접 백그라운드 명령을 실행하지 않음.
- 신규 QR·정책·입력·소켓 JUnit 24개는 CI 대기. 자세한 한계와 기기 체크리스트는 `LAN-AND-ANDROID-ENTRYPOINTS.md` 참고.

### 7단계

- 암호화는 Tink streaming AEAD 기반 별도 `.stbackup` 형식. 백업 암호는 저장하지 않으며 인증이 끝난 앱 전용 ZIP만 복원 경로로 전달. 원본 ZIP은 그대로 남음. 기존 Android 가져오기 제한과 일치하도록 원본 ZIP 8GiB를 처리 전에 확인하고 임시 ZIP 두 개의 공간도 검사.
- 독립 검토로 취소 직후 반환값 유실/작업 미착수 시 비밀값·임시 파일 정리, 큰 파일의 뒤늦은 제한 실패를 보완. 암호화 형식 JUnit 및 제공자 통합 검증은 구분해서 기록.
- 캐릭터 PNG·개별 채팅 JSONL 선택 복원은 기존 사용자 폴더만 지원. 같은 이름은 기본 건너뛰기, 항목별 덮어쓰기 선택. 캐릭터 연결·원본/대상 revision·정확한 경로를 재검사하며 미선택 데이터/API 키는 유지.
- 이전 버전 선택은 현재 로컬 브랜치의 직전 30개 커밋. 반드시 현재 전체 ZIP을 남긴 뒤 임시 코드·의존성을 준비하고 기존 복원 저널로 교체. 과거 데이터 롤백은 기록과 실제 ZIP의 Git 커밋이 모두 일치하는 전체 백업만 사용. 일반 업데이트 경로에는 이 전체 준비 비용을 추가하지 않음.
- 전체 복원은 해제 디렉터리 inode를 저널에 먼저 기록한 뒤 같은 파일시스템 안에서 이동. 전체 데이터를 다시 복사하지 않음. 기존 복구 경계 38개 회귀 통과. 서버 시작 대기 횟수는 유지하고 실제 소요 시간만 기록해 실기기 측정 근거를 남김.
- 독립 검토 보완: 다른 사용자 프로필의 개별 복원 저널 경로 허용, 실제 부모 FD 고정·새 파일 덮어쓰기 거부, 알 수 없는 외부 파일은 원복 과정에서도 삭제하지 않음. 기존 ZIP 생성 시의 원본 계획을 버전 교체 직전 재검사하며, Git 전환은 런처 메타데이터도 트리 밖에서 보존.
- 로컬 선택 복원 18개 저널 흐름(두 프로필·강제 종료·외부 파일 충돌), 9개 계획/경합 그룹, 버전 기록 8그룹, 실제 Git·ZIP 기반 버전 전환 7개 흐름 통과. 마지막 공통 경로 보완 이후 전체 Linux 회귀 및 Kotlin 실행은 통합 CI에서 확인.
- QR·암호화 라이브러리와 번들 구성 요소의 공식 라이선스·고지를 APK `assets/licenses`에 포함.

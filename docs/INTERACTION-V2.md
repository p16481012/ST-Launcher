# 인터랙션 v2 구현 및 확인 경로

기준: [Figma 인터랙션 v2, 84:461](https://www.figma.com/design/gyjatqqr77OuiNBoBdzDCC/?node-id=84-461). 그림의 파란 원은 탭 위치 설명이지 앱의 버튼이 아닙니다. 예시 용량·경로·성공 화면 대신 현재 설치 및 작업 결과를 표시합니다.

| 흐름 | APK에서 확인할 행동 |
| --- | --- |
| C1·C2 서버 | 홈에서 시작 → 홈 버튼에 진행 표시 → 준비되면 대화 열기. 종료는 확인창 없이 진행하며 종료 중 중복 실행되지 않습니다. |
| C3 설명 | 홈의 정보 아이콘 → 확인, 배경, 뒤로, 아래로 밀기 중 하나로 닫기. 짧고 느린 드래그는 원위치로 돌아옵니다. |
| C4 백업 | 지금 백업 → 범위 선택. **백업 시작** 전에는 파일을 쓰지 않습니다. 시작 후 시트를 접어 다른 탭으로 이동하고 미니 바를 눌러 다시 엽니다. 완료 알림의 보기로 해당 ZIP을 확인합니다. |
| C5 초기화 | 도구 → 초기화 → 백업 선택과 경고 확인. 취소·바깥 탭·뒤로는 아무 작업도 시작하지 않습니다. |
| C6 파일 | 파일을 길게 눌러 선택 → 추가 선택 → 휴지통. 복구 성공 시 원래 경로에 돌아온 항목을 강조합니다. |
| C7 탐색 | 홈 → 로그 → 뒤로는 홈, 도구 → 서버 로그 → 뒤로는 도구입니다. 현재 하단 탭을 다시 누르면 해당 탭의 첫 화면으로 돌아갑니다. |
| C8 화면 설정 | 글씨 크기·테마·강조색은 선택 즉시 적용합니다. 동작 줄이기에서는 이동·크기 애니메이션을 줄입니다. |
| C9 신규 연결 | 3단계 진입만으로 확인하지 않습니다. Termux 열기에서 명령 복사 → Termux에 붙여 넣고 Enter → 런처 복귀 시 한 번 확인합니다. 실패는 이 단계 안에서 안내합니다. |
| C10 포트 | 숫자 키패드, 유효 범위 1024–65535, 잘못 입력한 뒤 완료/포커스 해제 시 경고, 실행 중이면 저장하고 재시작을 확인합니다. |
| C11 외부 접속 | 스위치 → 보안 설정 → 확인 체크 → 적용 내용 확인. 저장 성공 전에는 켠 것으로 표시하지 않습니다. 끌 때 기존 인증 설정을 지우지 않습니다. |
| C12 로그 | 끝에서만 새 줄을 따라갑니다. 위로 스크롤하면 읽던 위치를 유지하고, 아래 화살표로 따라가기를 재개합니다. |
| C13 넓은 화면 | 도구·설정에서 왼쪽 목록은 그대로 두고 오른쪽 상세만 바꿉니다. |

검증은 모델 단위 테스트와 Android 휴대폰·태블릿의 Compose 입력 테스트를 분리합니다. 에뮬레이터 테스트는 제어된 상태를 사용하므로 실제 Termux, 다른 앱으로 전환하는 OS 동작, 제조사별 뒤로 가기 제스처까지 대신하지는 않습니다.

## 기존 관리 기능을 찾는 위치

| 예전 관리 탭에서 하던 일 | 새 화면 |
| --- | --- |
| 버전·브랜치·설치 위치·Node.js·커밋 확인 | 도구 → 설치 관리 → 설치 정보. 설정 → 앱 정보의 설치 정보 확인도 같은 화면을 엽니다. |
| 내부 저장소 폴더 또는 Termux 경로에서 기존 설치 가져오기 | 도구 → 설치 관리 → 기존 설치 가져오기. 폴더 검사 뒤 원본 유지/이동·대상 백업 여부를 정하는 확인 절차는 그대로입니다. |
| Release/Staging 전환, 점검·복구, 초기화 | 도구 → 설치 관리의 브랜치 및 유지관리 항목. 실행 전 경고·서버 종료 조건을 유지합니다. |
| 안전 검사, 전체/동일 버전의 새 커밋, Node 요구 사항, 여유 공간과 수정 파일 확인 | 도구 → 업데이트. 최신 상태에서도 검사 결과와 재검사 버튼이 남습니다. |
| 업데이트 전 자동 백업, 업데이트 실행, 이전 버전, 기록과 롤백 후 복원 | 도구 → 업데이트. 롤백 기록의 ZIP 확인·복원은 실제 백업 화면으로 연결됩니다. |
| 백업 만들기, ZIP 가져오기·복원, 공유·내보내기·삭제·고정·메모 | 하단 백업. 만들기는 ‘지금 백업’, ZIP별 작업은 그 백업을 선택합니다. |
| 안전 사본·휴지통, 공간 정리, Download 폴더, 암호화 저장/복원, 백업 알림 | 하단 백업의 관리·저장/알림 목록에 이름을 표시합니다. |

신규 설치 및 권한 연결은 처음 설정에 그대로 둡니다. 기존 사용자를 예전 관리 탭으로 보내는 우회 화면은 없습니다.

# ST-Launcher

Termux에서 SillyTavern을 설치하고 관리하는 비공식 Android 런처입니다.

**정식 빌드 버전: 0.1.0**

이 런처는 깡통 커뮤니티에서 제작·배포되었습니다. SillyTavern 및 Termux 공식 프로젝트와는 별개입니다.

## 주요 기능

- 기존 SillyTavern 연결 및 Release / Staging 설치·전환
- 서버 시작·종료·재시작, 상태 확인과 브라우저 열기
- 업데이트 확인·적용 및 실패 시 롤백
- 데이터·설정·확장 프로그램·전체 설치의 ZIP 백업과 복원
- 현재·이전 서버 로그 확인과 작업 결과 복원
- Termux 환경 진단, 오류 안내와 진단 보고서 복사
- 서버 주소·포트 설정 및 다양한 테마

Android 8.0 이상과 F-Droid판 Termux가 필요합니다. 최초 설정은 앱 안내를 따라 진행해 주세요.

설치용 정식 APK는 [릴리스](https://github.com/p16481012/ST-Launcher/releases)에서 제공합니다. 백업에는 개인정보·API 키가 포함될 수 있으므로 외부 공유에 주의해 주세요.

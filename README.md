# ST-Launcher

Termux에서 SillyTavern을 설치하고 관리하는 비공식 Android 런처입니다.

**정식 빌드 소스 버전: 0.3.2**

설치용 공개 버전은 아래 릴리스에서 확인해 주세요.

이 런처는 깡통 커뮤니티에서 제작·배포되었습니다. SillyTavern 및 Termux 공식 프로젝트와는 별개입니다.

## 주요 기능

- 홈에서 대화 열기·서버 시작을 바로 실행하고, 백업·도구·설정으로 이동합니다. 태블릿은 목록과 상세 정보를 나란히 보여줍니다.
- 기존 SillyTavern 연결 및 Release / Staging 설치·전환
- 서버 시작·종료·재시작, 상태 확인과 브라우저 열기
- 업데이트 확인·변경 내역 미리보기·적용 및 실패 시 롤백
- 데이터·설정·확장 프로그램·전체 설치의 ZIP 백업과 복원
- 백업 공유·다른 위치에 저장, 앱 안과 휴대폰에서 백업 시기 알림
- 충전 중 자동 백업(선택), 자동으로 만든 사본의 보관 개수 설정
- 백업 고정·메모·정리 미리보기, 내부 안전 사본과 저장 공간 확인
- ZIP 암호화 보관 및 캐릭터·채팅 선택 복원
- 외부 ZIP을 중간 변환 압축 없이 한 번만 해제해 직접 복원
- PC 데이터 ZIP 미리보기·사용자별 합치기. 새 자료만 추가하고, 같은 이름의 휴대폰 파일은 유지합니다.
- 도구의 자료 관리에서 캐릭터 카드와 배경을 둘러보고, 카드 없이 남은 채팅을 찾거나 옮긴 자료를 휴지통에서 되돌립니다.
- PNG 캐릭터 카드·배경·로어북·채팅 완성 프리셋·테마·빠른 답장을 각각의 목록에서 가져옵니다.
- 배경·로어북·채팅 완성 프리셋·테마·빠른 답장은 눌러서 미리보고, 사용처를 확인한 뒤 이름 변경·새 이름으로 복사·휴지통 이동을 할 수 있습니다.
- 내부 저장소·Termux의 기존 설치 가져오기 (원본 유지 또는 검증 후 이동 선택)
- 기존 설치 교체·복원 전 전체 ZIP 백업 선택
- 실제 SillyTavern 폴더 탐색, 새 파일·폴더 만들기, 텍스트 수정·파일·폴더 가져오기·이름 변경·삭제 취소
- Android 파일 화면에서 Termux 폴더 열기
- 현재·이전 서버 로그 확인과 작업 결과 복원
- 로그 검색·공유, 파일 검색·다중 선택·미리보기
- 작업 진행률과 상세 로그 표시 (측정 가능한 단계는 실제 용량·항목 수 진행률)
- Termux 환경 진단, 오류 안내와 진단 보고서 복사
- 서버 주소·포트 설정 및 다양한 테마
- 확장 프로그램 관리, LAN 주소·QR·접속 허용 설정
- 이전 버전 선택, 홈 바로가기·빠른 설정 타일·위젯

Android 8.0 이상과 F-Droid판 Termux가 필요합니다. 최초 설정은 앱 안내를 따라 진행해 주세요.

새 설치 전에는 기존 설정 파일을 유지하며 Termux 패키지를 함께 갱신하고, Node.js·npm이 정상 실행되는지 확인합니다. 실행 오류가 있으면 SillyTavern 다운로드 전에 중단하고 실제 오류 내용을 안내합니다.

기존 설치의 **도구 → 점검·복구**는 기본적으로 Termux 패키지 전체를 갱신하지 않습니다. Node.js가 필요한 라이브러리나 심볼을 찾지 못했을 때만 별도 갱신을 제안합니다. 동의하면 오류가 여전히 있는지 확인한 뒤 필요한 경우 Termux 패키지를 함께 갱신합니다. Node.js와 npm이 정상 실행돼야 SillyTavern 실행 모듈을 다시 구성합니다.

파일·ZIP 가져오기는 Android 10 이상에서 지원합니다. 파일 수정과 기존 설치 이동 전에는 서버를 종료해 주세요. 앱 내 텍스트 편집은 64 KiB까지 지원하며, 외부 폴더 열기는 Android 파일 화면에서 `SillyTavern` 폴더를 선택하는 방식입니다.

기존 설치 가져오기는 원본을 남기는 복사 또는 성공 후 원본을 지우는 이동을 선택할 수 있습니다. 이후 런처는 새 위치의 설치를 사용하며 원본과 자동 동기화하지 않습니다. 교체 전 전체 백업을 선택하면 데이터 크기만큼 시간·공간이 추가되며, 백업 실패 시 교체하지 않습니다. 이 전체 백업에는 API 키 등 비밀 설정도 포함되며 암호화되지 않습니다.

폴더 가져오기는 Termux가 접근 가능한 내부 저장소·Termux 홈의 폴더를 현재 위치로 복사합니다. 원본은 유지하며, 같은 이름의 기존 항목은 덮어쓰지 않습니다. 클라우드 폴더는 지원하지 않습니다.

설치용 정식 APK는 [릴리스](https://github.com/p16481012/ST-Launcher/releases)에서 제공합니다. 백업에는 개인정보·API 키가 포함될 수 있으므로 외부 공유에 주의해 주세요.

새로 만드는 ZIP에서 비밀 설정을 끄면 사용자별 `secrets.json`을 넣지 않습니다. `config.yaml`을 선택해도 외부 접속 로그인 정보를 뺀 사본만 넣으며, 그 사본으로 복원하면 외부 접속은 꺼집니다. 원래 설치의 설정은 바뀌지 않습니다. 이전 ZIP·다른 런처의 ZIP이나 채팅·확장 프로그램에 따로 저장한 비밀까지 제거되지는 않습니다.

백업 탭에서 ZIP을 선택해 재압축 없이 공유하거나 다른 위치에 저장할 수 있습니다. 직접 만든 백업의 공간 정리는 삭제할 항목을 확인한 뒤 진행합니다.

설정 → **백업 알림·자동 백업**에서 두 기능을 따로 고를 수 있습니다.

- **백업 알림:** 마지막 사용자 데이터·전체 백업 후 1일·7일·30일 중 선택한 기간이 지나면 홈과 백업 탭에 표시합니다. 휴대폰 알림을 켜고 Android에서 알림을 허용하면 앱 밖에서도 알려줍니다. 알림을 눌러도 백업이 바로 시작되지는 않습니다.
- **충전 중 자동 백업:** 기본은 꺼짐입니다. 켜면 Android가 충전 중이고 기기를 쓰지 않을 때 실행 기회를 잡습니다. 서버가 켜져 있거나 다른 작업이 진행 중이면 끄지 않고 건너뜁니다. 정해진 시각 실행을 보장하지 않습니다. 실행 결과는 설정에서 확인할 수 있습니다.
- **자동 사본 보관:** 새 백업이 확인된 뒤, 런처가 자동으로 만든 것으로 확인된 ZIP만 설정한 수(2·4·8개)에 맞춰 정리합니다. 직접 만든 백업·고정한 백업·출처를 확인할 수 없는 백업은 대상이 아닙니다.

암호화 백업은 원본 ZIP 8 GiB까지 지원하는 `.stbackup` 전용 형식이며, 원본 ZIP은 암호화되지 않은 채 남습니다. 암호 분실 시 복구할 수 없습니다. 복원에는 임시 ZIP 두 개와 해제 공간이 필요합니다. 이전 버전 변경은 현재 전체 ZIP을 먼저 보존하며, 과거 데이터까지 되돌리는 선택은 정확한 버전 기록이 있는 전체 백업에서만 가능합니다.

# ST-Launcher

Termux에서 SillyTavern을 설치하고 관리하는 비공식 Android 런처입니다.

**정식 빌드 버전: 0.1.0**

다음 업데이트(0.2.0) 개발 중입니다. 설치용 공개 버전은 아래 릴리스에서 확인해 주세요.

이 런처는 깡통 커뮤니티에서 제작·배포되었습니다. SillyTavern 및 Termux 공식 프로젝트와는 별개입니다.

## 주요 기능

- 기존 SillyTavern 연결 및 Release / Staging 설치·전환
- 서버 시작·종료·재시작, 상태 확인과 브라우저 열기
- 업데이트 확인·적용 및 실패 시 롤백
- 데이터·설정·확장 프로그램·전체 설치의 ZIP 백업과 복원
- 외부 ZIP을 중간 변환 압축 없이 한 번만 해제해 직접 복원
- 내부 저장소·Termux의 기존 설치 폴더 이동 (새 위치 검증 후 원본 삭제)
- 실제 SillyTavern 폴더 탐색, 새 파일·폴더 만들기, 텍스트 수정·파일·폴더 가져오기·이름 변경·삭제 취소
- Android 파일 화면에서 Termux 폴더 열기
- 현재·이전 서버 로그 확인과 작업 결과 복원
- 작업 진행률과 상세 로그 표시 (측정 가능한 단계는 실제 용량·항목 수 진행률)
- Termux 환경 진단, 오류 안내와 진단 보고서 복사
- 서버 주소·포트 설정 및 다양한 테마

Android 8.0 이상과 F-Droid판 Termux가 필요합니다. 최초 설정은 앱 안내를 따라 진행해 주세요.

파일·ZIP 가져오기는 Android 10 이상에서 지원합니다. 파일 수정과 기존 설치 이동 전에는 서버를 종료해 주세요. 앱 내 텍스트 편집은 64 KiB까지 지원하며, 외부 폴더 열기는 Android 파일 화면에서 `SillyTavern` 폴더를 선택하는 방식입니다.

폴더 가져오기는 Termux가 접근 가능한 내부 저장소·Termux 홈의 폴더를 현재 위치로 복사합니다. 원본은 유지하며, 같은 이름의 기존 항목은 덮어쓰지 않습니다. 클라우드 폴더는 지원하지 않습니다.

설치용 정식 APK는 [릴리스](https://github.com/p16481012/ST-Launcher/releases)에서 제공합니다. 백업에는 개인정보·API 키가 포함될 수 있으므로 외부 공유에 주의해 주세요.
